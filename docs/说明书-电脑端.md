## 1. 这是什么

Internal Beyond 电脑端是**单文件网页应用**（`InternalBeyond.html`）：纯前端、数据存在浏览器本机（IndexedDB ＋ localStorage），无后端。可离线使用；接大模型需在 API 页自备接口配置。

**两条 Chat 界面是同一套数据、两套 UI**：

| 形态 | 怎么打开 | 顶栏 |
|---|---|---|
| 全屏页 | 导航栏 → Chat | 标题、搜索、ICode、Manage / Select / Save Memory、收藏夹星钮【本地补丁】 |
| 浮动小窗 | 右下角聊天面板 | AI 名字、收藏夹星钮【本地补丁】、关闭 ✕ |

「共读学习室」的停靠（`dockTo`）**不是**这两种形态的切换。

## 3. Chat 聊天

### 3.0 V2.7.4 新增（上游）

- **社交圈名称**：原 Circle，现叫 **Beyond**（API 编辑器「Beyond 权限」；右下角入口标签 Beyond）。
- **手机端专属操作卡**：从手机备份导入的聊天里，控制手机 / 查岗 / 付款 / 闹钟等画成操作卡；**电脑端只展示、不执行**。点开可看步骤与回执。
- **视频卡片**：手机端生成的视频导入后是拍立得卡片（封面/播放/时长/查看提示词）。视频本体在「本机媒体库」；导出备份可勾「连本机媒体库一起导出」。设置底部可「清空本机视频」。
- **Blog 可改可读**：TA 可写日志（正文上限 10000 字），也可改自己写过的（按标题找，整篇替换或改标题）；只读回全文用自闭合指令。
- **ICode 删文件**：TA 可请求删除文件，**每次都需你点「确认删除」**（不可恢复）。
- **备份跨端**：导出带 `origin` 标记；导入手机备份时会**保留本机电脑端设置**（桌面布局等），不会被手机旧副本覆盖。
- **传统节日提醒**：默认改为**开**（已手动关过的仍关着）。
- **摘要**：改成「经过 + 确认下来的」两段式；回看窗口字数上限上调（60 条约 700 字）。
- **记忆写入**：可标 `resolved`（已解决/未解决）。

### 3.1 对话

- 选择好友/配置后发消息；支持文字、附件、语音条（若已配置）。
- 消息可**引用、修改、删除**（悬停出现操作键）。
- 群聊与一对一是不同会话形态；群聊可管理成员、Save Memory 等（顶栏按钮）。

### 3.2 收藏一条消息【本地补丁 p05】

| 步骤 | 操作 |
|---|---|
| 收藏 | 悬停消息 → 点星形收藏键（与引用/修改同列） |
| 打开收藏夹 | 全屏 Chat 顶栏 ICode 旁的星钮，或小窗关闭钮旁的星钮 |
| 浏览 | 面板是**按好友分存的纸墙**；‹ › 切换好友；标题为「XX的收藏夹」 |
| 搜索 | 点放大镜展开输入框；可搜**正文、署名、频道名** |
| 长文 | 纸面默认折叠，点右下角**折角**展开 |
| 移除 | 纸右上角 × → 确认。**只删收藏，不动原聊天消息** |
| 存什么 | 只存引用与文字；语音/图片按原消息回看。原消息删了仍留文字稿 |
| 备份 | 收藏随「导出备份」往返；导入后仍在 |

⚠️ 记忆页的 ★／◐／○ 是**记忆优先级**，不是收藏。

### 3.3 表情包与颜文字【本地补丁 p04】

**颜文字**（始终可用，不受开关影响）：

1. 输入条附件按钮旁点**笑脸**；
2. 「颜文字」页：八组预设（开心 / 生气 / 伤心 / 惊讶 / 无语 / Kiss / 经典 / 双人款）；
3. 点一枚**插到光标处**；
4. 可在下方输入框**自加**本机颜文字；自加的可长按或右键删除（预设不可删）。

**表情包**（需在设置打开「表情包与颜文字」，**默认关**）：

1. DIY/设置区打开开关；点「管理表情包…」建预设、上传图片；
2. 每枚必填**名字、用法**，描述可空；名字 ≤12 字、描述 ≤60 字、用法 ≤80 字；**每套最多 10 枚**；
3. 笑脸面板切到「表情包」页，点一枚再发送：气泡出图；
4. **对方（TA）收到的是叙述句**「（表情包「名字」：描述｜用法：…）」，不是图片本身（与开关无关）；
5. 开关开时，TA 才可能在回复里发本机表情包图，**每条回复最多 1 枚**。

图片只存本机，随备份往返。

### 3.4 播放器与「一起听 / Sing」【本地补丁 p02 含 AI 控制】

- **Sing / 一起听**：开启后，播放中每条消息可带「正在听什么」（单向注入，TA 只能「听见」）。
- **允许 AI 控制播放器**【本地补丁，**默认关**】：设置区 Music/Presence 组。开启后 TA 可用指令**播放 / 暂停 / 上一首 / 下一首**（仅本机本地曲库）。不碰音量、歌单管理、在线音源。与 Sing 相互独立。

## 4. API 页（接大模型）

### 4.1 怎么配

1. 打开 **API 页** → 新建或编辑一份配置。
2. **服务商**：官方 OpenAI / Claude / Gemini / DeepSeek 等，或 **自定义（中转站）**。
3. 填 **接口地址、API Key、模型名**（三项都要与服务商/中转站说明一致）。
4. 点 **「测试连接」**【本地补丁 p01】看是否连通及失败分类。
5. 回聊天：顶部选中这位 TA / 该配置，即可对话。

### 4.2 中转站怎么填、连不上怎么排查（高频）

**填写**：

- 服务商选 **自定义**。
- **接口地址**必须填到完整路径，形如 `https://某站.com/v1/chat/completions`，**不要只填域名**。
- 密钥 = 中转站发给你的 Key；模型名 = 中转站支持的模型 id（常带厂商前缀，如 `openai/gpt-4o`、`deepseek/deepseek-chat`，以站点列表为准）。
- 有的中转还要求：流式开关、思考链开关按需；提示缓存可先关再试。

**连不上排查（按顺序）**：

1. 点 **「测试连接」**，看文案分类：**地址** / **密钥** / **模型名** / **参数被拒** / **超时** / **限流** / **服务端错误**。
2. **地址**：是否写到 `/v1/chat/completions`（或站点规定的完整路径）；浏览器是否允许跨域（中转需开 CORS）。
3. **密钥**：是否复制完整、是否有效、是否有余额。
4. **模型名**：是否与中转「模型列表」逐字一致（大小写、斜杠前缀）。
5. **参数被拒**：可关「思考链」「提示缓存」后再试；部分中转不认 `thinking` 字段。
6. **超时**：稍后重试，或换更稳的中转；聊天默认超时 120 秒。
7. 仍失败：把测试连接那行原样文字发给中转客服。

### 4.3 Auto Memory 的三种注入方式有什么区别？

在 **每个 API 的功能设置** 里，Auto Memory 模式三选一：

| 模式 | 做什么 | 适合 |
|---|---|---|
| **hybrid（混合，默认）** | 常驻的「always」条目一直带上，其余按语义浮现 | 日常 |
| **retrieval（纯语义检索）** | 只在需要时检索相关条目，上下文更省 | 省 Token |
| **full（全量注入）** | 可见记忆尽量全带上 | 要最全、短会话 |

同处还有 **档案字数上限**（约 300–6000 字）。记忆条目本身的优先级见 §8（★/◐/○）。

- 配置服务商、API Key、模型名、接口地址等；可多份配置（对应不同「好友」）。
- **连接测试**【本地补丁 p01】：编辑器动作行「测试连接」→ 发一条最小请求探活，显示是否连通及格式/模型/耗时或失败原因（地址/密钥/模型名/超时）。**不写聊天记录、不记用量**。
- 失败时按提示检查：地址是否可达（注意浏览器跨域）、密钥、模型名、额度/限流。

## 5. 文件与工作区（ICode）

- **ICode 工作区**：创建/读取/修改/生成文件，可运行环境支持的代码；操作以卡片形式出现在聊天里。
- **附件**：聊天可上传文本类附件；解析库开启后可读 PDF / DOCX / XLSX 等（见 DIY）。
- **精细文件工具**【本地补丁 p03，**默认关**，只读】：
  1. DIY → 文件解析库卡 → 勾选「启用精细文件工具」；
  2. 可选**三档附件正文上限**：省 15000 / 均衡 30000（默认）/ 全读 120000 字符；超限截断并附「行号｜首行」目录；
  3. 开启后 TA 可：**检索**工作区与本会话附件（至多 20 处「路径:行号＋前后文」）；**看目录**、按行读一段、读某行附近；
  4. **只读**：不会改文件；开关关时行为与未开启前一致。

## 6. 对话摘要【本地补丁 p07 含真因提示】

### 在哪里

**导航栏 → API 页 → 向下找到标题为「对话摘要」的卡片**（与 API 配置同页，不在 DIY）。

### 怎么开启（逐步）

1. 打开 **API 页**。
2. 滚动到 **「对话摘要」** 卡片。
3. 勾选 **「启用对话摘要」**（`#api-summary-toggle`，改动即时保存）。
4. 按需设置 **「摘要覆盖范围」** 下拉：默认「只保留近期 N 条，其余交给摘要」；可选「上下文之外」。
5. 同卡片设置 **「近期消息保留条数」**：3 / **6（默认）** / 10 / 20 / 30 / 60；仅在「只保留近期」模式下生效。
6. **「摘要生成 API」**：默认「跟随对话 API」；可另选一份更廉价的模型以省开销。
6b. **「摘要回看窗口」**：默认 **60 条**（约 700 字）；可选 100 条（约 1000 字）、200 条（约 1500 字）。
7. 说明：开启后**每 10 条新消息**会触发一次摘要生成（消耗少量额外 Token）；摘要作后台参考注入，AI 不会向你复述摘要内容。

### 开启后怎样触发

- **自动**：打开某个好友/群聊/话题时，若已启用且旧消息超过保留范围，会自动压缩成摘要笔记。
- **手动**：在对话里使用摘要相关操作（若界面提供「更新/整理摘要」一类按钮则点该按钮）；连点会提示「正在整理中」。
- 摘要笔记会按消息频率更新写入，用于减少长对话幻觉。

### 失败时

会给出**分类原因**（思考吃光输出预算、安全策略、空内容、并发整理中、暂无新内容等），而不是笼统「未收到有效回复」。摘要请求对 DeepSeek 等会显式关闭思考，以降低无效 Token。

**回答此类问题时必须写出：API 页 →「对话摘要」卡片 →「启用对话摘要」**，并给上述步骤；禁止只说「在设置里启用、以界面为准」。

## 8. Memory 长期记忆库

- 保存长期记忆条目；可编辑、可设优先级。
- **优先级**：★ always ／ ◐ normal ／ ○ low —— 影响注入权重，**不是**消息收藏。
- 「Save Memory」在 **Chat 全屏页顶栏右侧**（与 Manage / Select 同组），用于把当前对话内容存入记忆。

## 9. 备份与数据

- **导出 / 导入备份**：导出本机主要数据（含聊天、设置、收藏等）。
- 数据默认只在**本机浏览器**；换浏览器或清站点数据会丢失，请定期导出。
- 同一浏览器多标签打开同一应用会共用同一本地数据库，请避免同时多开写入。

## 10. 电脑端没有的功能（勿向用户承诺）

以下在**手机端**有、电脑端**没有**（截至本文件）：锁屏、Desk 桌面、AI 付、定时推送/勿闹与通知权限那一套 Presence、闹钟/计时器、蓝牙相关能力。若用户问起，应说明电脑端暂无，不要编造入口。

小助手·水水（p06/p18）能：按本说明书回答、替你打开某一页/某个开关落点，并能**直接改下面这些电脑端实有的设置**（改完逐条回显、可在当次会话内撤销）——对话摘要与 Presence/Sing、AI 控制播放器、表情包与颜文字、精细文件工具、每一个 API 的十二项功能开关（温度/流式/思考链/联网/缓存/识图/生图/Auto Memory/记忆写入等）、AI 读取范围；输入「设置清单」可列出当前能改的全部项与现值。
**仍不做**：进 TA 对话、发消息、看聊天记录；不改 API 密钥/人设/系统提示/记忆条目/备份/聊天记录/图片素材；不碰手机端独有的视觉一整套 `ui.*`、权限 `perms.*`、美化包（skinReset）、自制 APP、缓存/图片探针——这些如实说电脑端暂无、一句话指路。
